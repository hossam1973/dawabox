# علبة الدواء (DawaBox)

تطبيق أندرويد عربي لتذكير المريض بأدويته، مع علبة دواء ناطقة وتنبيهات للمرافق.

## المميزات

| القسم | ما يفعله |
|---|---|
| **اليوم** | الجرعة التالية بزر كبير «أخذت الدواء»، أدوية اليوم مع أيقونة لكل شكل دواء، أزرار تم / فائتة / تراجع، بحث بالاسم أو بالصوت، تنبيه نفاد المخزون، مخطط الالتزام الأسبوعي |
| **العلبة** | محاكاة علبة ذكية بـ 7 حجرات وأضواء LED، تحدث معها بالصوت: «أخذت الدواء»، «ما جرعتي التالية؟»، «ما أدويتي اليوم؟»، «كم بقي من الدواء؟» وترد بصوت عربي |
| **أدويتي** | إضافة وتعديل وحذف: الاسم، الجرعة، الشكل، التكرار، الأوقات، تاريخ البدء، الحجرة، المخزون، التعليمات، وسائل التنبيه. يمكن ملء النموذج بالصوت |
| **السجل** | تقويم شهري ملون حسب الالتزام، واضغط أي يوم لترى الجرعات ووقت أخذها وطريقة تسجيلها |
| **التنبيهات** | بيانات المريض والمرافق، تفعيل كل وسيلة تنبيه، مهلة اعتبار الجرعة فائتة، زر تجربة كل الوسائل، حالة الأذونات |

### كيف تعمل التنبيهات
1. في موعد الجرعة: منبّه دقيق (`AlarmManager`) يُظهر إشعاراً بصوت المنبه مع أزرار **أخذته / بعد 10 دقائق / تخطي**، وتنطق العلبة اسم الدواء والجرعة والحجرة.
2. بعد المهلة (30 دقيقة افتراضياً): مهمة `WorkManager` تتحقق؛ إن لم تؤخذ الجرعة تُسجل فائتة ويُبلَّغ المرافق:
   - **SMS**: يُرسل تلقائياً إذا منحت إذن الإرسال.
   - **واتساب والبريد**: أندرويد لا يسمح بالإرسال الصامت، فيظهر إشعار فيه زر يفتح الرسالة جاهزة للإرسال.
3. تُعاد جدولة المنبهات بعد إعادة تشغيل الهاتف.

### علبة دواء حقيقية
التطبيق يتعامل مع واجهة `PillboxDevice` في `voice/Pillbox.kt`. حالياً `SimulatedPillbox` تستخدم سماعة الهاتف. لربط علبة حقيقية (بلوتوث BLE) اكتب صنفاً ينفذ نفس الواجهة وضعه مكانها في `MainViewModel`.

## منصة العيادة «تذكرة» والربط بينهما
مجلد `platform/` فيه منصة العيادة (صفحة ويب واحدة، افتح `platform/index.html` في المتصفح).

| من | إلى | كيف |
|---|---|---|
| العيادة | التطبيق | في المنصة: «رمز للتطبيق» بجانب المريض ← انسخ رمز `DAWA-RX:` وأرسله بالواتساب. في التطبيق: أدويتي ← استيراد وصفة من العيادة. تُضاف الأدوية والمواعيد وتُجدول تنبيهاتها. |
| التطبيق | العيادة | في التطبيق: التنبيهات ← إرسال تقرير الالتزام. الرسالة فيها رمز `DAWA-REPORT:`. في المنصة: الصقه في «تقرير من التطبيق» فيتحدث الالتزام الأسبوعي والمخزون. |

الصيغة واحدة في الطرفين: `data/ClinicLink.kt` و`rxCode()`/`importReport()` في المنصة. الربط لا يحتاج خادماً، ولذلك لا يتم تلقائياً؛ المزامنة الفورية تحتاج قاعدة بيانات سحابية (مثل Firebase).

### مواعيد الطبيب
تُضاف من تبويب «أدويتي» أو تأتي مع الوصفة، ويذكّر التطبيق بها قبل يوم وقبل ساعتين (إشعار ونطق).

## البناء
- افتح المجلد في **Android Studio** (Koala أو أحدث) واضغط Run، أو:
```bash
./gradlew assembleDebug
```
- أو ارفع المشروع إلى GitHub: ملف `.github/workflows/android.yml` يبني ملف APK تلقائياً، وتجده في صفحة Actions تحت Artifacts.

## ما لم يُضف بعد
- **إرسال البريد تلقائياً** يحتاج خادماً (مثل Firebase Functions مع SendGrid).
- **الدخول والمزامنة السحابية (Firebase)**: البيانات الآن محلية على الهاتف (Room). لإضافتها تحتاج ملف `google-services.json` من مشروع Firebase الخاص بك.
